# Session 2026-11-03 — Delete Class

## What shipped
**Delete Class** on the Classes dashboard (spec: `docs/specs/delete-class.md`).
- A red **Delete Class** button sits next to **Add Class**. It opens a card with a
  dropdown of classes; after an `hx-confirm` warning the chosen class is deleted
  together with its students, notes, and summaries.
- `store.DeleteClass` now cascades in one transaction and returns `ErrNotFound`
  for unknown ids. The schema has no `ON DELETE CASCADE` and `PRAGMA foreign_keys`
  is off, so dependent rows are deleted explicitly. Do not rely on the DB to cascade.
- `POST /classes/delete` (400 bad id, 404 unknown). Create and delete both render
  the `classListResponse` block, which refreshes the class cards and swaps the
  `#delete-class-select` dropdown out-of-band (`hx-swap-oob`), plus a
  `data-toast` span that triggers the existing toast.
- Checked by hand in a browser against a copy of the DB, not the real one.

  than through the plan → local build agent → review loop.

  (no `tail`, `grep`, or `2>/dev/null`). Do not use `SKIP_SECURITY_CHECK=1` or
  `--no-verify` unless the owner says so.
